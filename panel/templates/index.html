Server settings

Changing version or server type recreates the server container. Back up your world before doing this. Mods and plugins generally cannot be mixed across server types.

Add plugin or mod

Upload a trusted server-side .jar. Paper uploads go to data/plugins; Fabric/Forge/NeoForge uploads go to data/mods. Mod versions must match the server and players' modpacks.

Paper includes a basic built-in anti-x-ray. For a death-chest feature, install a compatible Paper grave/death-chest plugin from a trusted source. Cross-play and version-bridge plugins only work with compatible Paper builds; modded Java clients may not join Bedrock.
Security: this panel has Docker control access. It binds to localhost only; do not port-forward the panel port. Only forward the Minecraft Java TCP and Bedrock UDP ports if you want outside players to join. Use a whitelist for a private server.
