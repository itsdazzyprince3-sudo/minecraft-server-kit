Common settings

Changes are saved in shared .env/native config and apply after a restart. A world-name change selects a different save folder without deleting existing worlds; seed changes only affect newly generated terrain. Back up data/ first. Changing Minecraft version requires stopping the server, backing up all of data/, editing MINECRAFT_VERSION in .env, then running bash termux-run.sh --update and confirming in the terminal.
For stable running, keep Termux open, plug in the phone, use termux-wake-lock, and disable battery optimization for Termux where Android allows it. Doze and manufacturer policies can still suspend or kill the process. This is not guaranteed 24/7 hosting.
